// Setup

Three minutes.
One local AI.

01
Install Ollama
Download and install Ollama. It powers the local AI model that SuperPooper uses.
02
Download SuperPooper
Grab the latest Windows build and extract it anywhere on your computer.
03
Run setup.bat
Open the folder and run setup.bat. It installs everything SuperPooper needs automatically.
04
Launch SuperPooper
Start the app and begin chatting with your local AI.
