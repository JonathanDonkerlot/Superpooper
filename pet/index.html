Important — Read before running
Desktop Pet needs an image file to use as your pet character. You must provide your own image and it must be named exactly ct.png — the app won't start without it.

Place your ct.png file in the same folder as pet.exe before launching. Any PNG image works — a photo, a drawing, a cartoon character, anything you like. Transparent backgrounds look best.

// Customise

Make it yours.

Open pet.py in any text editor and tweak these four values at the top of the file.

PET_SIZE
PET_SIZE = 100
How big your pet is in pixels. Try 60 for tiny or 200 for enormous.
SPEED
SPEED = 0.05
How fast it follows your cursor. 0.02 is sleepy, 0.15 is snappy, 1.0 is instant.
OFFSET_X / OFFSET_Y
OFFSET_X = 20
OFFSET_Y = 20
How far from your cursor the pet sits. Negative values put it above or to the left.
IMAGE_PATH
IMAGE_PATH = "ct.png"
The filename of your pet image. Must be in the same folder. Must be a PNG.
